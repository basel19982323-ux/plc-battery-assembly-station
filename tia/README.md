# TIA Portal project archive

`BatteryStation.zap20` – TIA Portal **V20** project archive (PLC_1 CPU 1511-1 PN + HMI_1 TP700 Comfort + watch table), created with *Project → Archive* (restorable data discarded, ~1 MB).

**Open it:** TIA Portal V20 → **Project → Retrieve** → select the file → choose an empty target folder.

Then follow [../docs/getting-started.md](../docs/getting-started.md) from step 5 (start PLCSIM Advanced, download, run the HMI).
